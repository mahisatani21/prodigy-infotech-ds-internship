# 📊 Prodigy InfoTech – Data Science Internship

**Role:** Data Science Intern (Remote) | **Duration:** March 2026 – April 2026

This repository contains my work from the Data Science Internship at **Prodigy InfoTech**. Across five tasks, I worked with real-world datasets to practice data cleaning, exploratory data analysis (EDA), visualization, sentiment analysis, and predictive modeling using Python.

---

## 🎯 Objectives

- Clean and preprocess raw, real-world datasets
- Explore data and visualize patterns using statistical charts
- Perform sentiment analysis on social media text
- Build and evaluate a machine learning classifier
- Turn data findings into clear, actionable insights

## 🔍 Task Details

### Task 01 – Distribution Visualization
Visualized the distribution of a categorical or continuous variable (such as age or gender) using bar charts and histograms to understand how values are spread across a population.

### Task 02 – Data Cleaning & Exploratory Data Analysis
Cleaned the Titanic dataset by handling missing values, removing duplicates, and fixing inconsistent data. Explored relationships between variables (e.g., survival vs. age, gender, and class) to uncover key patterns.

### Task 03 – Decision Tree Classifier
Built a Decision Tree Classifier to predict customer behavior from demographic features. Evaluated the model using standard classification metrics.

### Task 04 – Sentiment Analysis
Analyzed social media text to classify sentiment (positive, negative, neutral) and visualized sentiment patterns to understand public opinion and engagement trends.

### Task 05 – Traffic Data Analysis
Analyzed traffic data to identify patterns and trends, using visualizations to highlight key factors and peak periods.
