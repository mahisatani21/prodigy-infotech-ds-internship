# 🚦 Traffic Accident Data Analysis & Visualization

## 📌 Task-05: Prodigy InfoTech Internship

### 📖 Project Overview

This project focuses on analyzing traffic accident data to identify key patterns related to **road conditions**, **weather**, and **time of day**. The goal is to uncover insights that can help improve road safety and reduce accident occurrences.

Using data analysis and visualization techniques, accident **hotspots** and contributing factors are identified effectively.

## 🎯 Objectives

* Analyze traffic accident data
* Identify patterns based on:

  * 🌧️ Weather conditions
  * 🛣️ Road conditions
  * ⏰ Time of day
* Visualize accident-prone areas (hotspots)
* Derive insights for better traffic management and safety

## 🛠️ Tech Stack

* **Python**
* **Pandas** – Data manipulation
* **Matplotlib & Seaborn** – Data visualization
* **Folium** – Geospatial visualization (heatmaps)

## 📊 Dataset

* Large dataset of traffic accidents (approx. 200,000 records)
* Contains details like:

  * Location (latitude & longitude)
  * Weather conditions
  * Road conditions
  * Time and date of accidents

## 🔍 Exploratory Data Analysis (EDA)

* Data cleaning and preprocessing
* Handling missing values
* Feature selection and transformation
* Identifying trends and correlations

## 🌍 Geospatial Analysis

* Used **Folium** to create interactive maps
* Generated **heatmaps** to highlight accident hotspots
* Visualized high-risk zones for better understanding

## 📈 Key Insights

* Certain weather conditions significantly increase accident risk
* Peak accident times observed during specific hours of the day
* Urban areas show higher accident density
* Road conditions play a crucial role in accident occurrence

## 📷 Visualizations

* 📊 Bar charts (weather & road conditions)
* 📉 Time-series plots (accidents over time)
* 🌍 Heatmaps (accident hotspots)

## 🚀 Conclusion

This analysis demonstrates how **data-driven insights** can help in:

* Improving traffic management
* Enhancing road safety measures
* Identifying high-risk areas for preventive actions
